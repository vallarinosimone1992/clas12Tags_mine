# MINE simulation provenance

When changing MINE physics, optical data, detector geometry assumptions, SiPM response or digitization, update `reference/` with the source or explicit user input, values/formula/units, affected configuration keys and files, active transport modes, rationale and limitations. Distinguish documented data, derivations, user inputs, assumptions and historical choices. Preserve source-specific provenance and reproducible extraction information next to optical datasets. Numerical validation is not experimental validation. See `reference/README.md`.
